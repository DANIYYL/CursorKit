# CursorKit
  
[![Live Demo](https://img.shields.io/badge/Live_Demo-View_Project-4CAF50?style=for-the-badge&logo=vercel&logoColor=white)](https://DANIYYL.github.io/CursorKit/)

## Features
 
- 34 cursors: CSS shapes (ring, halo, orbit, brackets, lens, glitch...) and canvas effects (fire, snow, matrix, lightning, plexus, snake...)
- 36 uniquely styled buttons with hover animations and a magnetic pull
- Works with mouse, pen and touch (the cursor follows your finger while you scroll)
- Live code panel with HTML / CSS / JS tabs and a copy button

## Run locally
 
```bash
npm install
npm run dev
```
